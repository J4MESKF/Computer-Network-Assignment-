# Assignment
Assignment 1
## Title
How the Internet Delivers a Web Page – Amazon India
## Objective
To study how the Internet loads the Amazon India webpage using networking protocols.
## Solution
The webpage is loaded by using DNS, TCP/IP, HTTPS, and cookies to establish a secure and reliable connection between the browser and the Amazon server.
## Output
The Amazon India homepage is displayed successfully in the user's browser after secure communication with the server.
## Conclusion
DNS, TCP, HTTPS, and cookies work together to provide fast, secure, and reliable web browsing.
